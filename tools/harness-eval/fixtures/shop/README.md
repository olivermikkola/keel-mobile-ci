# Shop

A tiny shop backend used to try out changes.

- `shop/cart.py` keeps the items a customer wants to buy.
- `shop/pricing.py` has discount and price formatting helpers.
- `shop/inventory.py` stores the products and lists them in pages of 10 items.
- `shop/config.py` holds the settings.

Run the tests with `python3 -m unittest discover tests`.
